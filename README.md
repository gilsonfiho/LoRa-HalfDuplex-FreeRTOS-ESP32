# 📡 LoRa Half-Duplex com FreeRTOS no ESP32 (Heltec V3)

Este projeto demonstra uma comunicação LoRa half-duplex entre dois dispositivos **Heltec ESP32 LoRa V3**, utilizando o sistema operacional **FreeRTOS** para gerenciar as tarefas de transmissão e recepção de forma assíncrona.

A principal ideia é mostrar como implementar uma comunicação ponto-a-ponto com **LoRa + FreeRTOS**, aproveitando o multitasking do ESP32.

## 🧰 Tecnologias

- ESP32 (Heltec WiFi LoRa 32 V3)
- LoRa (915 MHz)
- FreeRTOS (nativo do ESP32)
- Arduino Framework (PlatformIO ou Arduino IDE)
